# แนวทางต่อยอด

หลักสูตรนี้ใช้ระบบแจ้งปัญหา IT ภายในหน่วยงานเป็น Project หลัก เมื่อเส้นทางหลักทำงานได้แล้ว นำโครงเดียวกันไปใช้กับงานอื่นในมหาวิทยาลัยได้

## ระบบลงทะเบียนสอบหรือกิจกรรม

เทียบระบบแจ้งปัญหากับระบบลงทะเบียน:

- Create: ผู้สมัครส่งแบบฟอร์มลงทะเบียน
- Read: ผู้สมัครตรวจสถานะใบสมัครของตัวเอง
- Update: ADMIN ตรวจหลักฐานการชำระเงินหรือเปลี่ยนสถานะใบสมัคร
- Delete: ADMIN ยกเลิกหรือเก็บใบสมัครที่ไม่ถูกต้องไว้ในประวัติ

## อัปโหลดรูปภาพ

ใช้ Supabase Storage ควรเพิ่มหลังเข้าใจข้อมูลใน Table แล้ว เพราะไฟล์ที่อัปโหลดต้องมีข้อมูลประกอบ เจ้าของ และกฎสิทธิ์

## Login ด้วย Google (Google OAuth)

ใช้แทนบัญชีอีเมลและรหัสผ่านที่สร้างไว้ให้ได้ หลังเข้าใจขั้นตอน Login แล้ว ต้องตั้งค่าผู้ให้บริการ Redirect URL และโดเมนของระบบจริงเพิ่ม

## การแจ้งเตือน

เพิ่มได้หลังการเปลี่ยนสถานะทำงานแล้ว เช่น ส่งอีเมล LINE หรือ Push Notification เมื่อสถานะเปลี่ยน แต่ไม่อยู่ในเส้นทางหลัก 20 ชั่วโมง

## Docker

ช่วยให้ระบบทำงานเหมือนกันทุกเครื่องตอน Deploy แต่ Bootcamp นี้ใช้บริการสำเร็จรูปและ Deploy บน Vercel เพื่อให้นักศึกษาโฟกัสที่การทำงานของ Web Application
