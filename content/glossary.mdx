# คำศัพท์

## Authentication (การยืนยันตัวตน)

ตรวจว่าผู้ใช้คือใคร ในหลักสูตรนี้ผู้ดูแลสร้างบัญชีอีเมลและรหัสผ่านไว้ให้ก่อน นักศึกษาจึงเน้นเรื่อง Session และการป้องกันหน้าได้เต็มที่

## Authorization (การตรวจสิทธิ์)

ตรวจว่าผู้ใช้ที่ Login แล้วทำอะไรได้บ้าง ใน Project คือการแยกสิทธิ์ของ USER กับ ADMIN

## CRUD

งานพื้นฐานกับข้อมูล 4 อย่าง ได้แก่ Create (เพิ่ม), Read (อ่าน), Update (แก้ไข) และ Delete (ลบ) Project นี้เพิ่ม Issue ใหม่ อ่านรายการและรายละเอียด และให้ ADMIN เปลี่ยนสถานะ ส่วนการปิดงานใช้สถานะ `DONE` แทนการลบ

## Server Action

Function ที่ทำงานบน Server และฟอร์มใน Next.js เรียกใช้ได้โดยตรง ในหลักสูตรนี้ Server Action ตรวจข้อมูลก่อนส่งไปบันทึกที่ Supabase

## RLS (Row Level Security)

กฎใน Database ที่กำหนดว่าผู้ใช้แต่ละคนอ่านหรือแก้แถวใดได้บ้าง

## Managed Backend

Backend ที่ผู้ให้บริการดูแล Server ให้ ในหลักสูตรนี้ Supabase ให้ทั้ง Postgres, Auth และ RLS แต่นักศึกษายังต้องเข้าใจว่า Backend รับผิดชอบอะไร

## Checkpoint Branch

Branch ที่เก็บ Project ในสถานะที่ทำงานได้แน่นอน นักศึกษาที่ตามไม่ทันใช้ Branch นี้กลับมาเรียนต่อพร้อมห้องได้

## LLM-Safe Coding (ใช้ AI เขียนโค้ดอย่างปลอดภัย)

ใช้ AI ช่วยอธิบาย หากรณีที่อาจผิดพลาด และช่วยตรวจความปลอดภัย แต่ไม่ส่ง Secret ให้ AI และตรวจโค้ดด้าน Login หรือสิทธิ์ที่ AI สร้างทุกครั้งก่อนใช้
