# Login, Logout, and Protected Pages

## Day 5 - ชั่วโมงที่ 2: Login และป้องกันส่วนที่ต้องมีผู้ใช้

### เป้าหมายของชั่วโมงนี้

หลังจบชั่วโมงนี้ นักศึกษาจะสามารถ:

1. สร้าง Login และ Logout ด้วย Server Action
2. อ่านผู้ใช้ปัจจุบันจาก Session
3. บังคับให้ Login ก่อนเปิดหน้าและก่อนบันทึกข้อมูล
4. แสดงเมนูตามสถานะ Login

### ไฟล์ที่ใช้

```text
app/actions.ts             ← แก้ไข
app/login/page.tsx         ← สร้างใหม่
lib/auth.ts                ← สร้างใหม่
app/issues/new/page.tsx    ← แก้ไข
components/AppNav.tsx      ← สร้างใหม่
app/layout.tsx             ← แก้ไข
```

## Slide 1: ต่อจาก Hour 1

ตอนนี้ Server Client และ Proxy อ่านและต่ออายุ Session ใน Cookie ได้แล้ว

**ปัญหา:** ยังไม่มีหน้า Login ผู้ใช้จึงเข้าสู่ระบบไม่ได้

**ชั่วโมงนี้:** สร้าง Login และ Logout ให้ครบตามลำดับนี้

```text
Login → Supabase ตรวจบัญชี → เก็บ Session → ใช้งาน → Logout
```

รหัสผ่านถูกส่งไปตรวจที่ Server Action และไม่ถูกเก็บใน State หรือ Table ของ Project

## Slide 2: เตรียมบัญชีสำหรับทดลอง

<LessonCallout type="action">เปิด **Supabase Dashboard → Authentication → Users** แล้วสร้างบัญชี `user@example.com` และ `admin@example.com`</LessonCallout>

- ตั้งรหัสผ่านที่จำได้สำหรับทดลอง
- เปิด **Auto Confirm User** เพื่อให้ Login ได้ทันทีโดยไม่ต้องยืนยันอีเมล

ระบบแจ้งปัญหาเป็นระบบภายในองค์กร ผู้ดูแลจึงสร้างบัญชีให้ ไม่เปิดให้คนทั่วไปสมัครเอง

ตอนนี้ทั้งสองบัญชีใช้งานได้เหมือนกัน Hour 3 จะกำหนดให้ `admin@example.com` เป็น ADMIN

## Slide 3: เพิ่ม Action สำหรับ Login

<LessonCallout type="action">แก้บางส่วนใน `app/actions.ts`: เพิ่ม Import ต่อจาก Import เดิม แล้วเพิ่ม `signInAction` ท้ายไฟล์</LessonCallout>

<CodeChange language="ts" addedLines="1">

```ts
import { createClient } from "@/lib/supabase/server";
```

</CodeChange>

<CodeChange language="ts" addedLines="1,2,3,4,5,6,7,8,9">

```ts
export async function signInAction(formData: FormData) {
  const email = String(formData.get("email") ?? "").trim();
  const password = String(formData.get("password") ?? "");
  const supabase = await createClient();
  const { error } = await supabase.auth.signInWithPassword({ email, password });
  if (error) redirect("/login?error=1");
  revalidatePath("/", "layout");
  redirect("/issues");
}
```

</CodeChange>

`signInWithPassword` ให้ Supabase ตรวจบัญชีแล้วเก็บ Session ใน Cookie ส่วน `revalidatePath("/", "layout")` ให้เมนูอ่านสถานะ Login ใหม่

## Slide 6: สร้าง Helper อ่านผู้ใช้

<LessonCallout type="action">สร้างไฟล์ใหม่ `lib/auth.ts` แล้วใส่โค้ดนี้ทั้งไฟล์</LessonCallout>

<CodeChange language="ts" addedLines="1,2,4,5,6,7,8,10,11,12,13,14">

```ts
import { redirect } from "next/navigation";
import { createClient } from "@/lib/supabase/server";

export async function getCurrentUser() {
  const supabase = await createClient();
  const { data } = await supabase.auth.getUser();
  return data.user;
}

export async function requireUser() {
  const user = await getCurrentUser();
  if (!user) redirect("/login");
  return user;
}
```

</CodeChange>

`getCurrentUser` คืนผู้ใช้หรือ `null` ส่วน `requireUser` พาไป `/login` ถ้ายังไม่ Login

## Slide 13: ทดสอบ Login และ Logout

<LessonCallout type="action">ทดสอบตามลำดับนี้ ตั้งแต่ยังไม่ Login จนถึง Logout</LessonCallout>

1. เปิด `/issues/new` ตอนยังไม่ Login: ถูกพาไป `/login`
2. ใส่รหัสผ่านผิด: เห็นข้อความ "อีเมลหรือรหัสผ่านไม่ถูกต้อง"
3. Login ด้วย `user@example.com`: ไป `/issues` และเมนูแสดงอีเมล
4. แจ้งปัญหาใหม่: บันทึกได้
5. กด **ออกจากระบบ**: กลับ `/login` และเปิด `/issues/new` ไม่ได้อีก

ถ้า Login แล้วเมนูไม่เปลี่ยน ให้ตรวจ `revalidatePath("/", "layout")` ใน `signInAction`

Hour 3 จะแบ่งสิทธิ์ USER และ ADMIN ให้ Database ตรวจจริง
