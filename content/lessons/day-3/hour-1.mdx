# Tailwind Setup and Utilities

## Day 3 - ชั่วโมงที่ 1: เปลี่ยนจาก Custom CSS มาใช้ Tailwind

หลังจบชั่วโมงนี้ นักศึกษาจะสามารถ:


## Slide 1: ต่อจากสิ่งที่สร้างใน Day 2

ตอนนี้ CSS ที่เขียนเอง (Custom CSS) ของทุกหน้าอยู่ใน `app/globals.css` ไฟล์เดียว

**ปัญหา:** เมื่อ Component เพิ่มขึ้น ไฟล์ CSS จะยาวขึ้น และต้องสลับไฟล์ TSX กับ CSS ไปมาทุกครั้งที่แก้หน้าตา

**ชั่วโมงนี้:** เปลี่ยนมาใช้ Tailwind โดยหน้าตาเว็บใกล้เคียงเดิม และการทำงานไม่เปลี่ยน

## Slide 2: จาก Custom CSS ไปสู่ Tailwind

แบบเดิมต้องตั้งชื่อ Class แล้วเขียน CSS แยกอีกไฟล์:

```tsx
<button className="primary-button">ส่งข้อมูล</button>
```

```css
.primary-button {
  padding: 12px 16px;
  background: #0f766e;
  color: white;
}
```

Tailwind มี Class สำเร็จรูป เรียกว่า **Utility Class** แต่ละตัวทำหน้าที่เดียว เช่น กำหนดสีหรือระยะห่าง แล้วเขียนรวมกันใน `className` ได้เลย:

```tsx
<button className="bg-teal-700 px-4 py-3 text-white">
  ส่งข้อมูล
</button>
```

## Slide 3: ตรวจว่า Tailwind พร้อมใช้งาน

<LessonCallout type="action">เปิด `package.json` และ `postcss.config.mjs` ในโฟลเดอร์หลักของโปรเจกต์ แล้วตรวจว่ามีรายการตามตัวอย่าง (มีแล้วไม่ต้องแก้)</LessonCallout>

Day 2 เลือก Recommended Defaults จึงติดตั้ง Tailwind v4 มาแล้ว

ใน `package.json` ต้องมี:

```json
"tailwindcss": "^4",
"@tailwindcss/postcss": "^4"
```

ใน `postcss.config.mjs` ต้องมี:

```js
const config = {
  plugins: { "@tailwindcss/postcss": {} },
};

export default config;
```

`@tailwindcss/postcss` แปลง Class ของ Tailwind เป็น CSS ที่ Browser ใช้ได้

## Slide 4: เปิด Tailwind โดยเก็บ CSS เดิมไว้

<LessonCallout type="action">แก้บางส่วนใน `app/globals.css`: เพิ่ม Import บนสุด แล้วครอบ CSS เดิมทั้งหมดด้วย `@layer base`</LessonCallout>

<CodeChange language="css" addedLines="1,3,5">

```css
@import "tailwindcss";

@layer base {
  /* CSS เดิมทั้งหมด รวมถึง @media */
}
```

</CodeChange>

Comment `/* ... */` บอกตำแหน่งของ CSS เดิม ไม่ต้องคัดลอก ตลอดชั่วโมงนี้ Comment ในตัวอย่างใช้บอกตำแหน่งแบบเดียวกัน

ครอบด้วย `@layer base` เพราะถ้าไม่ครอบ CSS เดิมจะทับ Class ของ Tailwind จน Class ที่เพิ่มไม่มีผล

`app/layout.tsx` Import `globals.css` อยู่แล้ว ทุกหน้าจึงใช้ Tailwind ได้ทันที

## Slide 6: อ่าน Class พื้นฐาน

| Class | ความหมาย |
|---|---|
| `p-4`, `px-6`, `py-8` | ระยะด้านในกล่อง: ทุกด้าน, ซ้าย–ขวา, บน–ล่าง |
| `mt-2` | ระยะด้านนอกกล่องด้านบน |
| `gap-4` | ระยะห่างระหว่างส่วนย่อยที่เรียงกัน |
| `text-sm`, `text-xl`, `font-bold` | ขนาดตัวอักษร และความหนา |
| `text-slate-600`, `bg-white` | สีตัวอักษร และสีพื้น |
| `border border-slate-200`, `rounded-lg` | เส้นขอบสีเทาอ่อน และมุมโค้ง |

ตัวเลขยิ่งมาก ระยะ ขนาด หรือความเข้มของสียิ่งมาก เช่น `p-4` เท่ากับ 16px และ `p-6` เท่ากับ 24px

## Slide 7: จัดเมนูนำทาง

<LessonCallout type="action">แก้บางส่วนใน `app/layout.tsx`: เปลี่ยน Class ของ `<nav>` กับ `<div>` แล้วใส่ `className` ชุดเดียวกันให้ Link ทั้งสามรายการ</LessonCallout>

<CodeChange language="tsx" addedLines="1,2,4">

```tsx
<nav className="border-b border-slate-200 bg-white" aria-label="เมนูหลัก">
  <div className="mx-auto flex max-w-5xl flex-wrap gap-2 px-6 py-3">
    <Link
      className="rounded-md px-3 py-2 font-semibold text-slate-700 hover:bg-slate-100"
      href="/"
    >
      หน้าแรก
    </Link>
    {/* Link อีกสองรายการ ใส่ className ชุดเดียวกัน */}
  </div>
</nav>
```

</CodeChange>

- `flex flex-wrap` เรียง Link ในแถวเดียว และขึ้นบรรทัดใหม่เมื่อที่ไม่พอ
- `mx-auto max-w-5xl` จัดเมนูไว้กลางหน้า โดยไม่ยืดเต็มจอกว้าง
- `hover:` ทำงานเฉพาะตอนชี้เมาส์ ในที่นี้พื้นหลังของลิงก์เป็นสีเทาอ่อน

## Slide 10: จัดกรอบและแถวของ `IssueForm`

<LessonCallout type="action">แก้บางส่วนใน `components/IssueForm.tsx`: เพิ่ม `className` ให้ `<section>`, `<h2>`, `<form>`, `<fieldset>` และ `<legend>` แล้วเปลี่ยน `form-row` เป็น Class ของ Grid</LessonCallout>

<CodeChange language="tsx" addedLines="1,2,3,4,5,6">

```tsx
<section className="rounded-lg border border-slate-200 bg-white p-6">
  <h2 className="text-xl font-bold text-slate-950">แจ้งปัญหาใหม่</h2>
  <form className="mt-4">
    <fieldset className="grid gap-4">
      <legend className="text-sm font-semibold text-slate-700">ข้อมูลปัญหา</legend>
      <div className="grid gap-4 md:grid-cols-2">
        {/* ช่องชื่อและอีเมลเดิม */}
      </div>
      {/* ช่องหัวข้อ รายละเอียด และปุ่มเดิม */}
    </fieldset>
  </form>
</section>
```

</CodeChange>

- `md:grid-cols-2` แบ่งช่องชื่อและอีเมลเป็น 2 คอลัมน์เมื่อจอกว้างตั้งแต่ 768px ถ้าจอแคบกว่านั้นจะเรียงลงมา
- Tailwind เขียน Style ของจอเล็กก่อน แล้วใช้ `sm:` (640px), `md:` (768px) หรือ `lg:` (1024px) เพิ่ม Style ของจอที่กว้างขึ้น

## Slide 11: ปรับช่องกรอก

<LessonCallout type="action">แก้บางส่วนใน `components/IssueForm.tsx`: แทนกลุ่มช่อง `title` เดิมด้วยโค้ดนี้ แล้วใส่ Class ชุดเดียวกันให้ช่องชื่อและอีเมล</LessonCallout>

<CodeChange language="tsx" addedLines="1,2,7,8">

```tsx
<div className="grid gap-2">
  <label htmlFor="title" className="text-sm font-semibold text-slate-800">
    หัวข้อปัญหา
  </label>
  <input
    id="title" name="title" type="text" required
    className="w-full rounded-md border border-slate-300 px-3 py-2 text-sm
      focus:border-teal-700 focus:outline-none focus:ring-4 focus:ring-teal-100"
  />
</div>
```

</CodeChange>

`focus:` ทำงานเมื่อช่องกรอกถูกเลือก เช่น คลิกหรือกด Tab มาถึง จึงเห็นกรอบสีเขียว

ช่องชื่อและอีเมลให้คง `id`, `name`, `type` และ `required` เดิมไว้ ส่วนช่องรายละเอียดทำในขั้นถัดไป

## Slide 13: ลบ CSS เดิมของโครงหน้า

<LessonCallout type="action">แก้บางส่วนใน `app/globals.css`: ลบชุดกฎของเมนูนำทาง, `header`, `footer` และ `.issue-list` ภายใน `@layer base`</LessonCallout>

<CodeChange language="css" removedLines="1,2,3,4,5,6,7,8">

```css
.app-nav { /* ค่าเดิม */ }
.app-nav-inner { /* ค่าเดิม */ }
```

ลบแต่ละชุดตั้งแต่ชื่อจนถึง `}` ที่ปิดชุดนั้น โดย `header` ต้องลบรวม `h1` ที่ซ้อนอยู่ข้างใน

`.issue-list` ลบได้เพราะ `gap-6` ของ `<main>` เว้นระยะแทนแล้ว ส่วน `main` และ `section` เก็บไว้ก่อน เพราะหน้าอื่นและ `IssueList` ยังใช้อยู่

## Slide 14: ลบ CSS เดิมของ Form

<LessonCallout type="action">แก้บางส่วนใน `app/globals.css`: ลบชุดกฎของ Form ทั้งหมดตามตัวอย่าง ภายใน `@layer base`</LessonCallout>

<CodeChange language="css" removedLines="1,2,3,4,5,6,7,8,9">

```css
fieldset { /* ค่าเดิม */ }
legend { /* ค่าเดิม */ }
.form-group { /* ค่าเดิม */ }
label { /* ค่าเดิม */ }
input, textarea { /* ค่าเดิม */ }
input:focus, textarea:focus { /* ค่าเดิม */ }
textarea { /* ค่าเดิม */ }
button { /* ค่าเดิม รวม &:hover ที่ซ้อนอยู่ */ }
@media (min-width: 720px) { /* .form-row ที่ซ้อนอยู่ */ }
```

</CodeChange>

`button` ต้องลบรวม `&:hover` ที่ซ้อนอยู่ข้างใน ส่วน `@media` ลบทั้งชุดได้เพราะข้างในมีแค่ `.form-row`

ใน `@layer base` จะเหลือ `*`, `body`, `main`, `section`, ตาราง และสถานะ ซึ่ง Hour 2 จะย้ายต่อ
