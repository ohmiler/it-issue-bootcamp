# Tailwind Setup and Utilities

## Day 3 - ชั่วโมงที่ 1: เปลี่ยนจาก Custom CSS มาใช้ Tailwind

### เป้าหมายของชั่วโมงนี้

หลังจบชั่วโมงนี้ นักศึกษาจะสามารถ:

1. อธิบายได้ว่า Tailwind CSS ช่วยเขียน Style อย่างไร
2. เปิดใช้งาน Tailwind ใน Next.js Project ได้
3. อ่าน Class พื้นฐานของ Tailwind ได้
4. แปลงเมนู หน้า Home และ Form จาก CSS เดิมเป็น Tailwind ได้
5. ลบ CSS เดิมเฉพาะส่วนที่ย้ายเสร็จแล้วได้

```text

```

## Slide 1: ต่อจากสิ่งที่สร้างใน Day 2

ตอนนี้ CSS ที่เขียนเอง (Custom CSS) ของทุกหน้าอยู่ใน `app/globals.css` ไฟล์เดียว

**ปัญหา:** เมื่อ Component เพิ่มขึ้น ไฟล์ CSS จะยาวขึ้น และต้องสลับไฟล์ TSX กับ CSS ไปมาทุกครั้งที่แก้หน้าตา

**ชั่วโมงนี้:** เปลี่ยนมาใช้ Tailwind โดยหน้าตาเว็บใกล้เคียงเดิม และการทำงานไม่เปลี่ยน

## Slide 2: จาก Custom CSS ไปสู่ Tailwind

เดิมเราตั้งชื่อ Class แล้วเขียน CSS แยกอีกไฟล์:

```tsx
<button className="primary-button">ส่งข้อมูล</button>
```

```css
.primary-button {
  padding: 12px 16px;
  background: #0f766e;
  color: white;
}
```

Tailwind มี Class สำเร็จรูป เรียกว่า **Utility Class** แต่ละตัวทำหน้าที่เดียว เช่น กำหนดสีหรือระยะห่าง แล้วเขียนรวมกันใน `className` ได้เลย:

```tsx
<button className="bg-teal-700 px-4 py-3 text-white">
  ส่งข้อมูล
</button>
```

## Slide 3: ตรวจว่า Tailwind พร้อมใช้งาน

<LessonCallout type="action">เปิด `package.json` และ `postcss.config.mjs` ในโฟลเดอร์หลักของโปรเจกต์ เพื่อตรวจว่ามีรายการตามตัวอย่าง ถ้ามีแล้วไม่ต้องแก้</LessonCallout>

Day 2 เลือก Recommended Defaults จึงติดตั้ง Tailwind v4 มาแล้ว

ใน `package.json` ต้องมี:

```json
"tailwindcss": "^4",
"@tailwindcss/postcss": "^4"
```

ใน `postcss.config.mjs` ต้องมี:

```js
const config = {
  plugins: { "@tailwindcss/postcss": {} },
};

export default config;
```

`@tailwindcss/postcss` แปลง Class ของ Tailwind เป็น CSS ที่ Browser ใช้ได้

## Slide 4: เปิด Tailwind โดยเก็บ CSS เดิมไว้

<LessonCallout type="action">แก้บางส่วนใน `app/globals.css`: เพิ่ม Import บนสุด แล้วครอบ CSS เดิมทั้งหมดด้วย `@layer base`</LessonCallout>

<CodeChange language="css" addedLines="1,3,5">

```css
@import "tailwindcss";

@layer base {
  /* CSS เดิมทั้งหมด รวมถึง @media */
}
```

</CodeChange>

Comment `/* ... */` บอกตำแหน่งของ CSS เดิม ไม่ต้องคัดลอกไปวาง ตลอดชั่วโมงนี้ Comment ในตัวอย่างใช้บอกตำแหน่งแบบเดียวกัน

ต้องครอบด้วย `@layer base` เพราะถ้าไม่ครอบ CSS เดิมจะชนะ Class ของ Tailwind ทำให้ Class ที่เพิ่มไม่เห็นผล

`app/layout.tsx` Import `globals.css` อยู่แล้ว ทุกหน้าจึงใช้ Tailwind ได้โดยไม่ต้อง Import เพิ่ม

## Slide 6: อ่าน Class พื้นฐาน

| Class | ความหมาย |
|---|---|
| `p-4`, `px-6`, `py-8` | ระยะด้านในกล่อง: ทุกด้าน, ซ้าย–ขวา, บน–ล่าง |
| `mt-2` | ระยะด้านนอกกล่องด้านบน |
| `gap-4` | ระยะห่างระหว่างส่วนย่อยที่เรียงกัน |
| `text-sm`, `text-xl`, `font-bold` | ขนาดตัวอักษร และความหนา |
| `text-slate-600`, `bg-white` | สีตัวอักษร และสีพื้น |
| `border border-slate-200`, `rounded-lg` | เส้นขอบสีเทาอ่อน และมุมโค้ง |

ตัวเลขยิ่งมาก ระยะ ขนาด หรือความเข้มของสียิ่งมาก เช่น `p-4` เท่ากับ 16px และ `p-6` เท่ากับ 24px

## Slide 7: จัดกรอบเมนูนำทาง

<LessonCallout type="action">แก้บางส่วนใน `app/layout.tsx`: เปลี่ยน Class ของ `<nav>` และ `<div>` ที่ครอบ Link โดยเก็บ Link ทั้งสามรายการและ `{children}` ไว้</LessonCallout>

<CodeChange language="tsx" addedLines="1,2">

```tsx
<nav className="border-b border-slate-200 bg-white" aria-label="เมนูหลัก">
  <div className="mx-auto flex max-w-5xl flex-wrap gap-2 px-6 py-3">
    {/* Link ทั้งสามรายการเดิม */}
  </div>
</nav>
```

</CodeChange>

- `flex` เรียง Link ในแถวเดียว และ `flex-wrap` ให้ขึ้นบรรทัดใหม่เมื่อที่ไม่พอ
- `max-w-5xl` จำกัดความกว้างไม่ให้ยืดเต็มจอกว้าง
- `mx-auto` จัดกล่องให้อยู่กลางหน้า

## Slide 8: ตกแต่งลิงก์ในเมนูนำทาง

<LessonCallout type="action">แก้บางส่วนใน `app/layout.tsx`: เพิ่ม `className` ชุดนี้ให้ Link ทั้งสามรายการ โดยคงข้อความและ `href` เดิม</LessonCallout>

ตัวอย่าง Link หน้าแรก:

<CodeChange language="tsx" addedLines="2">

```tsx
<Link
  className="rounded-md px-3 py-2 font-semibold text-slate-700 hover:bg-slate-100"
  href="/"
>
  หน้าแรก
</Link>
```

</CodeChange>

`hover:` ทำให้ Class หลังเครื่องหมาย `:` ทำงานเฉพาะตอนชี้เมาส์ ในที่นี้พื้นหลังจะเป็นสีเทาอ่อน

เมนูควรแสดงครบทุกหน้า และพื้นหลังของลิงก์เปลี่ยนเมื่อชี้เมาส์

## Slide 9: แปลง Header เป็น Tailwind

<LessonCallout type="action">แก้บางส่วนใน `app/page.tsx`: แทน `<header>...</header>` ภายใน `Home()` ด้วยโค้ดนี้</LessonCallout>

<CodeChange language="tsx" addedLines="1,2,3,4,7">


## Slide 12: จัดช่องชื่อและอีเมลเป็นสองคอลัมน์

<LessonCallout type="action">แก้บางส่วนใน `components/IssueForm.tsx`: เพิ่ม `className` ให้ `<form>`, `<fieldset>` และ `<legend>` แล้วเปลี่ยน `form-row` เป็น Class ของ Grid</LessonCallout>

<CodeChange language="tsx" addedLines="1,2,3,4">

```tsx
<form className="mt-4">
  <fieldset className="grid gap-4">
    <legend className="text-sm font-semibold text-slate-700">ข้อมูลปัญหา</legend>
    <div className="grid gap-4 md:grid-cols-2">
      {/* ช่องชื่อและอีเมลเดิม */}
    </div>
    {/* ช่องหัวข้อ รายละเอียด และปุ่มเดิม */}
  </fieldset>
</form>
```

</CodeChange>

`md:grid-cols-2` แปลว่า เมื่อจอกว้างตั้งแต่ 768px ให้แบ่งเป็น 2 คอลัมน์ ถ้าจอแคบกว่านั้นจะเรียงลงมาคอลัมน์เดียว

Tailwind เริ่มเขียนจากจอเล็กก่อน แล้วใช้ `sm:` (640px), `md:` (768px) หรือ `lg:` (1024px) เพิ่ม Style สำหรับจอที่กว้างขึ้น

## Slide 13: ปรับช่องกรอก

<LessonCallout type="action">แก้บางส่วนใน `components/IssueForm.tsx`: แทนกลุ่มช่องกรอก `title` เดิมด้วยโค้ดนี้ แล้วใช้ Class ชุดเดียวกันกับอีกสามช่อง</LessonCallout>

<CodeChange language="tsx" addedLines="1,2,7,8">

```tsx
<div className="grid gap-2">
  <label htmlFor="title" className="text-sm font-semibold text-slate-800">
    หัวข้อปัญหา
  </label>
  <input
    id="title" name="title" type="text" required
    className="w-full rounded-md border border-slate-300 px-3 py-2 text-sm
      focus:border-teal-700 focus:outline-none focus:ring-4 focus:ring-teal-100"
  />
</div>
```

</CodeChange>

`focus:` ทำงานเมื่อช่องกรอกถูกเลือก เช่น คลิกหรือกด Tab มาถึง จึงเห็นกรอบสีเขียว

ช่องชื่อ อีเมล และรายละเอียด ให้คง `id`, `name`, `type`, `rows={5}` และ `required` เดิม ส่วน Textarea เพิ่ม `resize-y` เพื่อให้ยืดได้เฉพาะแนวตั้ง

## Slide 15: ลบ CSS เดิมของโครงหน้า

<LessonCallout type="action">แก้บางส่วนใน `app/globals.css`: ลบชุดกฎของเมนูนำทาง, `header`, `footer` และ `.issue-list` ภายใน `@layer base`</LessonCallout>

<CodeChange language="css" removedLines="1,2,3,4,5,6,7,8">


ลบ `.issue-list` ด้วย เพราะ `gap-6` ของ `<main>` เว้นระยะแทนแล้ว ถ้าเก็บไว้ระยะจะห่างซ้ำสองชั้น

## Slide 16: ลบ CSS เดิมของ Form

<LessonCallout type="action">แก้บางส่วนใน `app/globals.css`: ลบชุดกฎของ Form ทั้งหมดตามตัวอย่าง ภายใน `@layer base`</LessonCallout>

<CodeChange language="css" removedLines="1,2,3,4,5,6,7,8,9">

```css
fieldset { /* ค่าเดิม */ }
legend { /* ค่าเดิม */ }
.form-group { /* ค่าเดิม */ }
label { /* ค่าเดิม */ }
input, textarea { /* ค่าเดิม */ }
input:focus, textarea:focus { /* ค่าเดิม */ }
```

`button` ต้องลบรวม `&:hover` ที่ซ้อนอยู่ข้างใน ส่วน `@media` ลบทั้งชุดได้เพราะข้างในมีแค่ `.form-row`

ใน `@layer base` จะเหลือ `*`, `body`, `main`, `section`, ตาราง และสถานะ ซึ่ง Hour 2 จะย้ายต่อ
